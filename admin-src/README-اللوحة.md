# مصدر لوحة تحكم كنف

هذا المجلد هو **مصدر** اللوحة. المجلد الشقيق `admin-ui/` هو ناتج بنائه،
وهو ما يخدمه Express فعلياً من نفس الأصل.

## لماذا المصدر هنا؟

اللوحة الأولى بُنيت خارج المستودع، فضاع مصدرها ولم يبقَ إلا الحزمة
المصغّرة. حين احتجنا حذف مسار قديم اكتشفنا — بعد أن تعطّلت اللوحة على
الإنتاج — أن الحزمة تناديه، ولا مصدر نراجعه. المصدر هنا حتى لا يتكرر ذلك.

## البناء

```bash
cd admin-src
npm install
npm run build      # يكتب في ../admin-ui ويمسح القديم
```

ثم ادفع `admin-ui/` مع التغيير. الخادم لا يبني اللوحة عند الإقلاع عمداً —
البناء خطوة واعية، لا أثر جانبي لإعادة تشغيل.

## التطوير المحلي

```bash
npm run dev
```

يعمل على منفذ Vite، لكن **الدخول لن ينجح منه**: كوكي الجلسة
`SameSite=Strict`، فلا يُرسل من أصل مختلف عن الخادم. للاختبار الحقيقي
ابنِ ثم افتح اللوحة من عنوان الخادم نفسه.

## الخريطة

| الملف | المسؤولية |
|---|---|
| `src/theme.js` | الألوان والتسميات وتنسيق التواريخ ومقارنة الأدوار |
| `src/api.js` | طبقة الشبكة: كوكي، تجديد صامت عند 401، ترجمة رموز الخطأ للعربية |
| `src/ui.jsx` | المكوّنات المشتركة — بما فيها `ReasonPrompt` |
| `src/App.jsx` | الهيكل والقائمة وبوابة الصلاحية |
| `src/pages/*` | شاشة لكل قسم |

## قاعدتان لا تُخرقان

1. **الصلاحية تُطبَّق في الخادم.** إخفاء عنصر من القائمة راحة عين لا حماية،
   وكل مسار يفحص الدور بنفسه ويردّ 403 لمن كتب العنوان يدوياً.
2. **ما لا يجب أن يُرى لا يُرسَل.** نص اليومية وإجابات المقاييس التفصيلية
   ومحتوى الدفاتر لا تصل إلى المتصفح أصلاً — إخفاؤها في الواجهة يبقى
   كشفاً في الشبكة.
